# Trace Analysis

Trace analysis is a separate program to process trace files generated by the SOP Solver.


## Usage

To produce a trace file from SOP Solver, include the path to write the trace file to as the 4th parameter:
- `> ./sop_solver <instance_file> <thread_count> <config_file> <trace_file>`

To analyze the trace file:
- `> cd trace_analysis`
- `> make`
- Process a single trace file:
  - `> ./sop_trace <trace_file>`
- Compare two trace files for differences:
  - `> ./sop_trace <trace_file1> <trace_file2>`
